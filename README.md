# DrawPad
Mobile-first drawing PWA: brushes (pen, airbrush, marker, feather eraser), smudge, auto-adapting light tool, picture import with move/scale/rotate/flip, warp mesh, liquify, per-layer blend modes, layers, undo/redo, two-finger zoom/pan, PNG export, IndexedDB autosave, offline.
Live: https://bradfuturez.github.io/drawpad/
